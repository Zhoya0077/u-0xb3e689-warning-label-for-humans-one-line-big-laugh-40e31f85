A program that writes one single-line safety warning label for every human being — funny first, plausible second — for make.fun's "Warning Label for Humans: One Line, Big Laugh" bounty ($5 in USDC).

## The entry

The program writes this 136-character label to `entry.txt` (no trailing newline):

> WARNING: This human ignores all warning labels, including this one, and will absolutely touch the thing you just told them not to touch.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=./output node main.ts
```
